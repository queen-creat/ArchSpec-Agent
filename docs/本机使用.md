# ArchSpec Agent 本机版

在自己的电脑上查找建筑规范、阅读正文和核对原页，无需租服务器或开通云数据库。首次下载不附带规范资料；官方搜索需要联网，取得的文件和查询记录保存在本项目的 `data/` 中。 下载本身超过来源登记上限时，没有完整原件，不能当成已有正文；只有已完整下载但处理失败的文件才能保留原件。

## 第一次使用

1. 在 GitHub 项目页面点击 **Code → Download ZIP**，将下载的压缩包解压到电脑上的普通文件夹。
2. Windows 双击 `启动本机版.bat`；macOS 双击 `启动个人版.command`。Linux 在项目目录执行 `sh 启动本机版.sh`。
3. 首次联网启动时，程序会从 uv 官方网站下载运行工具（已安装则复用），再准备 Python 和项目依赖。请保持启动窗口打开并等待。
4. 在本机设置窗口填写自己的 DeepSeek API Key；也可以暂时跳过。记下窗口里的登录账号，点击“复制登录密码”，再点“开始使用”。服务启动完成后浏览器会自动打开本机页面。
5. 输入窗口显示的账号并粘贴复制的密码登录，即可查找规范。使用时保持启动窗口打开；关闭它即可停止本机服务。以后再次双击同一启动文件即可。

如果已经有模型配置，向导会保留已有文件并提供打开配置文件的按钮。模型 Key 和本机账号只保存在本机，不放进网址或日志。首次下载的源码不附带规范原件；可通过官方来源联网获取。

Mac 若提示无法打开脚本，请右键点击文件并选择“打开”，按系统提示操作；也可在终端进入项目目录后执行 `sh 启动本机版.sh`。如果无法弹出设置窗口，请按本页下方的手动配置步骤操作。不要关闭系统安全保护。首次安装需要访问 [uv 官方安装服务](https://docs.astral.sh/uv/getting-started/installation/)；如果网络不可用，请检查网络后重新启动。

## 手动启动（备用）

已安装 uv 时，在项目目录运行：

```text
uv sync --frozen --no-dev
uv run --frozen --no-dev --offline --no-env-file python scripts/run_local.py --personal --port 8010
```

手动启动后访问 `http://127.0.0.1:8010/`。本机账号保存在 `data/local-access/personal-access.private.env`；端口被占用时，修改端口后重新启动。此入口只监听本机，不会自动创建外网分享。

## 查找与阅读

首次试用可以先查《民用建筑设计统一标准》。取得正文后，再输入“楼梯净宽”，选择候选查看原页。这个示例不需要模型或 Tavily Key；官方来源不可用时仍会显示缺口。

也可试查“宜昌市建筑日照间距的计算公式”，查看地方正文与原页；主文件和补充文件分别保留，仍需核对现行性及项目适用条件。

输入问题后先查询本机缓存，开启联网搜索时再按实际缺口补查官方来源。搜索摘要不是规范正文，只有取得并核对的正文才进入阅读区。可以打开出处、切换原页或下载原件；版本、地域适用性和识别文字仍需核对。

按完整规范名称查询时，使用出版方公开目录整理的题名词表；词表不代表规范现行或正文已经取得。官方公告紧接主批准句明确写出名称与编号变化时，可据此对应新名称附件；修订附件仍单独保留，不替代完整规范。

查询需要明确书目时，可补充公开规范名称或编号；本地正文仍可直接查阅。对外搜索使用公开查询词。

无 Key 时仍可使用本地关键词查找和已有免费官方搜索路线；官方站点不响应时会如实显示缺口，不保证每份规范都能自动取得。扫描 PDF 默认在本机识别，不下载额外语义模型；应用在本机推理库初始化前关闭其 1DS 遥测后台上传；个人入口对已登记、来源对应的官方正文及修订 PDF 使用每份 80 MiB／500 页上限，仍逐页识别并串行处理，较大扫描件需要等待。修订附件单独保留，不自动合并成完整规范；超预算或识别失败时保留原件，不能把它当作已可检索正文。

## 手动配置模型与搜索 Key（备用）

不配置也能启动。先执行以下命令，生成空的私有配置模板：

```text
uv run --frozen --no-dev python scripts/run_local.py --prepare-config
```

命令只创建缺少的模型和搜索配置文件，不读取或覆盖已有文件，不启动服务或调用 API。模板的 Key 留空，Tavily 免费确认默认关闭。用文本编辑器打开需要的文件填写；不需要的可以留空。

需要模型辅助理解和按出处整理时，编辑 `data/local-access/personal-model.private.env`：

```dotenv
DEEPSEEK_API_KEY=填你自己的Key
```

模型建议的公开规范若已有本机正文，会在原读取上限内优先查阅；这不会代替你选择检索范围。当自然问题尚无公共检索词时，同一次模型理解也可建议已登记的公开规范名称，再沿官方搜索补查；建议书名不证明版本、适用性或已取得正文，不额外启动一次选书模型调用。已有相似资料但仍无法回答、且建议书目确实缺正文时，也会沿同一流程补查；已准备或读取受限的建议正文不会因此自动重复获取。

工作台默认选中 DeepSeek；填写自己的 Key 并重启后，主动点击“查找条文”即可使用模型理解问题。可在“更多选项”关闭 DeepSeek。模型请求可能计费，并受本机累计预算限制；刷新或恢复历史不会自动调用。不要把 Key 填进源码或提交 GitHub。

已有 Tavily 账号并确认关闭按量付费后，编辑 `data/local-access/personal-tavily.private.env`：

```dotenv
TAVILY_API_KEY=填你自己的Key
ARCHSPEC_TAVILY_FREE_ONLY_CONFIRMED=true
```

在 macOS/Linux 将私有文件权限限制为仅本人读写，例如：

```text
chmod 600 data/local-access/personal-model.private.env
chmod 600 data/local-access/personal-tavily.private.env
```

只对实际创建的文件执行命令，保存后重新启动前台服务。不要发送 Key 到聊天、截图或问题输入框。搜索发送的是公开查询词；模型是否发送正文由页面的发送确认和服务端权限共同约束。

## 本地资料

取得的规范、查询记录和配置保存在本项目的 `data/` 中。更新代码前可单独备份该目录，代码更新不会替代个人资料备份。源码仓库不附带规范原件、账号、模型 Key 或个人数据库。
